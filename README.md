**Assignment 1: Random Projections**

We analyze two datasets using Sparse Random Projections and evaluate classification accuracy as a function of the number of retained dimensions.

**Datasets used:**
- COIL-20 (Columbia Object Image Library): 16,384-dimensional grayscale images of 20 objects
- Breast Cancer Wisconsin (Diagnostic): 30-dimensional tabular medical data

---

**Assignment 2: Clustering and Kernels**
We compare clustering algorithms and kernel SVMs across two datasets, evaluating structure discovery and classification performance under different model assumptions and evaluation metrics.

**Datasets used:**
- Seeds (UCI, ID 236): 210 wheat kernel samples across 3 varieties with 7 geometric features
- Heart Disease (UCI, ID 45): 303 patient records with 13 clinical features, binary disease diagnosis target
